# China public holiday data

Source: https://github.com/NateScarlet/holiday-cn/tree/2026.01.01
Version: 2026.01.01 (vendored snapshot; no runtime requests)
License: MIT; Copyright (c) 2019 NateScarlet. Full text: licenses/holiday-cn-2026.01.01.LICENSE.

2025 and 2026 contain published holiday and makeup-day records; 2027 is an empty placeholder and is treated as unavailable. Only listed dates are applied; adjacent-year announcements can contain December dates. Normal weekends need not be listed. Data does not infer an employer schedule or future announcements.

2026 dates were cross-checked against the State Council notice republished at https://www.beijing.gov.cn/fuwu/bmfw/sy/jrts/202511/t20251104_4258838.html ; original source links remain in the JSON papers fields.
