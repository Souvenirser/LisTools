# China public holiday data

Source for 2025 and 2026: https://github.com/NateScarlet/holiday-cn/tree/2026.01.01
Source for 2027: https://github.com/NateScarlet/holiday-cn/tree/a91748e8d6dd21ede3728a2f5bbb16e3a30daf6e (tag 2026.11.05)
License: MIT; Copyright (c) 2019 NateScarlet. Full text: licenses/holiday-cn-2026.01.01.LICENSE.

The snapshots are bundled for offline use. Only listed dates are applied. Adjacent-year announcements can contain December dates. Normal weekends need not be listed. Data availability follows the published records.

2026 dates were cross-checked against the State Council notice republished at https://www.beijing.gov.cn/fuwu/bmfw/sy/jrts/202511/t20251104_4258838.html ; original source links remain in the JSON papers fields.
2027 dates include 29 days off and five makeup days from the State Council notice at https://big5.www.gov.cn/gate/big5/www.gov.cn/zhengce/content/202611/content_7085101.htm .
