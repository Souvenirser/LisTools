# LisTools

独立的 Chrome 实用工具箱，覆盖开发和日常办公。提供 JSON、编码转换、计算器、日期、二维码、图片、PDF、文本、单位、计时等实用工具，复用开源编辑器和专用算法库。除手动测速连接公共节点外，其余工具均离线处理，不申请扩展权限。

项目采用 [MIT 许可证](./LICENSE)，欢迎通过 [Issue](https://github.com/Souvenirser/LisTools/issues) 反馈问题，通过 Fork 和 Pull Request 提交改进，详见 [贡献指南](./CONTRIBUTING.md)。

## 安装到 Chrome

需要 Chrome 120 或更新版本。

1. 将本地候选包 `releases/LisTools-1.3.3.zip` 解压到固定目录；已发布的历史版本也可从 [Releases](https://github.com/Souvenirser/LisTools/releases/latest) 下载。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角的 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择解压后直接包含 `manifest.json` 的目录。
4. 固定 LisTools 图标，点击后展开工具菜单，选择工具会在新标签页打开。页面内点击左上角 LisTools 可切换工具。

GitHub 的 **Source code** 压缩包是源码，需要按下文构建后加载 `dist/`。本项目目前通过 GitHub 分发扩展包，尚未上架 Chrome 应用商店；手动安装的版本需要自行下载更新并在扩展管理页重新加载。

当前源码为 **v1.3.3 候选版本**，本地构建生成 `LisTools-1.3.3.zip`；保留旧版本扩展包，不自动发布。

## 在 IntelliJ IDEA 中开发

使用 Node.js 22.12+ 或 24+（本地验证环境为 Node.js 26）。先获取源码：

```bash
git clone https://github.com/Souvenirser/LisTools.git
cd LisTools
```

在 IDEA 中选择 **Open** 打开项目目录，在项目终端运行：

```bash
npm ci
npm run dev
```

打开终端显示的本地地址即可开发。项目不依赖 Java、Maven 或 Gradle，不需要提交 `.idea` 配置。

## 界面语言与显示

顶部语言菜单提供 50 种界面语言，使用各语言的母语名称。默认采用上次选择；首次访问匹配浏览器首选语言，无法匹配时使用英语。简体、繁体中文分别匹配，阿拉伯语、波斯语、希伯来语和乌尔都语使用从右向左的布局。

语言切换只更新界面，保留当前输入、转换结果、编辑器展开状态及对比位置；JSON、文件名、时间戳、ISO 时间和时区标识不参与翻译。所有语言包随扩展打包，离线可用，仅保存语言偏好。编辑器可定制的主要菜单和右键菜单已接入翻译；组件未开放翻译接口的内部提示保留原文。

蓝色按钮表示主要操作，浅青色突出时间转换结果，绿色、红色和琥珀色分别标记成功或新增、错误或删除、修改或待重新对比。代码内容始终从左向右显示。

## 首版功能

- 粘贴 JSON、导入或直接拖入本地文件，美化、压缩、2/4 空格缩进、自动美化。
- 文本和树形视图、节点展开/折叠、全部展开/折叠、全文搜索。
- 复制全文、下载完整 JSON；折叠和视图切换不会截断导出内容。
- 大整数、长小数、指数与负零保留原始数字表示；错误给出行列和输入定位。
- 解析任务运行于 Worker，新输入会取消旧任务；错误或空输入不会残留上一次结果。
- 全部资源打包到扩展本地；不上传、不存储输入，不申请网页访问权限。

编辑器使用虚拟渲染，屏幕上的 DOM 行数不代表数据总量。树形视图的大数组分段展示，点击组件的更多项提示可继续浏览；超长字符串也可继续展开。文本视图支持完整搜索。全文复制和下载始终使用完整结果。

超过 2,000 个节点或 100 万字符的结果，在树形视图点击「全部展开/折叠」会自动切换到文本视图执行。开源组件的树形视图不对完全展开的全部节点做虚拟渲染，这样可以避免大量 DOM 卡住页面；树形单分支展开保持可用。

“合并”按收起/折叠节点实现，不包含两份 JSON 的数据合并。二维码功能使用独立工具页。

JSON 文件可拖到工作台任意位置，松开后自动读取并美化。文件导入不受「自动美化」开关影响，该开关仅控制键入/粘贴时的自动处理。拖入时显示落点提示，离开或松开后自动收起；一次支持一个文件。文件内容仍使用相同的严格 JSON 解析器校验，非法内容显示错误位置。

## JSON / 文本对比

从左上角 LisTools 菜单选择「JSON / 文本对比」进入，选择 JSON 结构或纯文本模式。左右两侧可粘贴、导入或分别拖入文件；两侧文件读取完成后自动对比。顶部显示差异总数及新增、删除、修改数量，原值标红、新值标绿，行内变化加深标色。

下方左右编辑区均可直接修改，支持粘贴、撤销和重做。编辑后保留当前内容，顶部显示「待重新对比」，点击「重新对比」或按 Cmd/Ctrl + Enter 更新统计。编辑区内容会在重新比较、打开上方输入区、交换左右、导入文件或切换模式时同步，避免每次输入都复制大文件全文。JSON 重新比较会统一排版；文档内容没有因此改变时保留撤销记录。

使用「上一处 / 下一处」或输入差异编号后按 Enter 定位，JSON 模式显示字段路径，文本模式显示两侧行号。默认收起未变化行，取消勾选可浏览全文；两侧支持搜索，JSON 还支持节点折叠。上方输入内容修改会清除旧视图；下方编辑过程中临时写错 JSON 时，重新比较会显示错误并保留编辑区，可直接修正或定位错误。计算期间可以取消，继续编辑也会终止旧任务；交换左右会重新对比。

JSON 对比会分别校验两侧输入，每侧展示首个错误，避免一个错误引发大量连带提示。简体中文界面显示错误归属、中文原因、修正建议、行列、字符 Unicode 编号和附近片段，两侧均有独立定位按钮；未成功计算时差异数量显示「—」。文件使用严格 UTF-8 解码并兼容开头 BOM；导入失败不会继续使用旧内容自动比较。Worker、计算、格式化和显示异常与 JSON 语法错误分别提示。常见错误和实测结果见 [错误诊断验收记录](./docs/diff-errors-verification.md)。

计数按 JSON 字段路径：一个值变化算一处，新增或删除整个节点各算一处。忽略排版及对象键顺序，数组按索引比较，插入/移动元素可能使后续多个索引产生差异。大整数和长小数按精确数值比较，`1`、`1.0`、`1e0` 相同；结果按统一键顺序展示，等价数值沿用首次遇到的写法。

纯文本模式接受普通文本、日志、SQL、Markdown 等，不要求合法 JSON；保留空格与大小写，CRLF/CR 换行统一为 LF，空文本也可以比较。按连续变化行块计数，相邻修改可能合并为一处；计数口径与 JSON 字段数不同。先用 JsDiff 按行比较，再用 CodeMirror 标记行内变化。切换模式比较当前显示的内容，JSON 模式此前的排版会保留。

全量结构比较、行级比较和文本高亮计算均在 Worker 执行；编辑器按可见区域渲染，输入时仅由 CodeMirror 进行限时局部高亮。复杂文本比较有计算预算，可能合并为较粗的高亮块和文本计数；JSON 顶部字段计数仍然精确。输入、解析树、格式化文本和差异位置都需占用内存，不承诺无限大小或任意深度。基础验证见 [发布验证记录](./docs/release-verification.md)，本次编辑和文本模式的本地验证见 [补充验收记录](./docs/diff-edit-text-verification.md)。

大 JSON 直接根据结构差异生成高亮范围，避免再搜索两份全文；仅值变化时复用排版，稀疏结果以小补丁传输。上方输入区同样使用虚拟编辑器，已排版的文档可直接复用。超长变化字段保留完整内容和准确计数，但可能整段高亮。页面耗时包含输入准备、Worker 和首屏显示；50 MB 样例的首次导入、重新比较及复现步骤见 [性能验收记录](./docs/diff-performance-verification.md)。

## 时间戳转换

从左上角 LisTools 菜单选择「时间戳转换」进入。默认读取系统设置的设备时区，不申请地理定位；可下拉选择 IANA 时区，或点击「恢复设备时区」。读取失败时回退 UTC 并显示提示。时间和时区转换均在本地完成，资源包含在扩展内，无需联网。

- 顶部每秒刷新当前时间、秒时间戳和毫秒时间戳，分别支持复制屏幕显示值。
- 「时间戳 → 时间」支持自动识别 10 位秒和 13 位毫秒；0 直接处理，其他长度（含早期和负时间戳）可手动选择单位。输入为十进制整数，不支持小数和科学计数法。
- 「时间 → 时间戳」支持 `YYYY-MM-DD HH:mm:ss`、最多三位小数秒和带 `Z` / `±HH:mm` 的 ISO 时间。无偏移时按所选时区解析，带偏移时以输入偏移确定时间点，所选时区只影响展示。
- 两个转换区独立，输入、单位或时区变化后自动更新；提供「填入当前」「清空」、单项复制和「复制全部」。整数秒向下取整，毫秒完整保留。
- 使用 IANA 时区规则计算对应日期的偏移，支持夏令时及非整小时时区；历史日期的秒级偏移也完整保留，ISO 输入支持对应的 `±HH:mm:ss`。夏令时跳过或重复的当地时间明确报错；重复时刻可补充显式偏移加以区分。非法日期不会自动修正为其他日期。
- 空输入或错误会清除该区结果并禁用复制。输入不上传、不保存，时区规则随浏览器内置数据更新。

实现复用 MIT 开源库 [temporal-polyfill](https://github.com/fullcalendar/temporal-polyfill)，本地测试和浏览器验收边界见 [时间戳验收记录](./docs/timestamp-verification.md)。

## 编码与转换

从左上角 LisTools 菜单的「开发工具 → 编码与转换」进入。页面左侧直接列出全部 37 个转换工具，分类只作文字分区、不需要展开，点击工具即可切换；支持中文、英文与 `decode`、`urlencode` 等别名搜索。通用转换页面提供中文和英文文案，其他语言暂回退英文；MD5 专用界面及其公共控件提供 50 种语言。具体算法诊断保留上游原文或中文详情。

| 分类 | 功能 |
| --- | --- |
| 基础编码 | Base64、Base64URL、Base32、Base32Hex、Base58 Bitcoin、Hex、二进制字节串 |
| 转义与 URL | URL 组件、完整 URI、表单组件、HTML/XML 实体、JSON 字符串、Unicode 转义与码点 |
| 字符集 | UTF-8、UTF-16LE/BE、GBK、GB18030、Big5、Shift_JIS、EUC-KR、Windows-1252 |
| 数据格式 | JSON ↔ YAML、XML ↔ 保序 JSON、CSV/TSV ↔ JSON、JSON Lines ↔ 数组、Query String ↔ JSON |
| 摘要与令牌 | MD5、SHA-1/224/256/384/512、SHA3-256/512、RIPEMD-160、BLAKE2b/s、BLAKE3、CRC32、HMAC-SHA256/384/512、JWT 仅解码 |
| 压缩 | Gzip、Zlib、原始 Deflate，文件 / Base64 / Hex 输入输出 |
| 数值与单位 | 2～36 进制整数、位/字节 SI/IEC 单位、固定时间长度、HEX/RGB/HSL/HSV 颜色 |
| 文本 | 大小写、命名风格、逐行去空白/空行/去重/排序、换行符、Unicode 规范化 |

小文本延迟 350 ms 自动转换；超过 256 KiB 或导入文件后手动运行。Cmd/Ctrl + Enter 执行，运行中可取消。修改输入、参数或工具后旧结果立即失效。文件保留原始字节，左侧只读预览不会替代原文件。「结果作为输入」显式替换输入，二进制结果仍保留字节类型。

- 可编辑文本最多 10 MiB（UTF-8），文件最多 50 MiB，输出及解压最多 100 MiB。大结果仅预览前 1 MiB，复制和下载始终使用完整结果。文件作为编码文本导入时仍遵循文件上限。Base58 遵从上游限制：原始字节 2 KiB / 编码文本 4 KiB，大文件使用 Base64 或 Hex。
- 编码、摘要不修剪空白、不统一换行、不移除 BOM；字符集无法无损转换时报错。解码结果无法作为所选字符集显示时提供 Hex 预览和原始字节下载。
- JSON 重复键报错，大数与数字原文保留。YAML 使用 JSON 数据模型、单文档、有限别名；XML 使用 `fast-xml-parser` 保序数组映射，反向需要同样结构，禁止 DTD 和外部实体。
- CSV/TSV 默认保持单元格字符串，表头与列数必须一致；null、嵌套值需显式选择 JSON 单元格模式。Query String 使用键对应字符串数组以保留重复参数。格式转换不保留源文件注释、排版或引号写法。
- JWT 始终标明「仅解码，未验签」，不根据解码成功判断令牌有效。HMAC 密钥仅用于当前任务，完成、取消或离开工具后清空。
- 大整数使用 BigInt；单位计算精度 200 位、显示最多 30 位有效数字，舍入标记 `≈`；颜色保留透明度并说明量化。
- 压缩复用 fflate 同步流，解压复用浏览器 `DecompressionStream`，逐块检查大小并验证完整性与校验和。Gzip 只接受单个 member，拒绝拼接流。全部处理运行于本地模块 Worker，不产生 Blob Worker。

输入、结果、JWT、HMAC 密钥不进入历史、日志、地址或持久存储；地址仅记录工具 ID。HTML/SVG 仅作为数据处理，不执行、不加载外部资源。没有任意脚本、AES/RSA、配方链或目录批处理。使用说明和实际验收边界见 [转换工作台验收记录](./docs/convert-verification.md)。

## MD5 摘要与校验

从侧栏「MD5 摘要」进入 `convert.html#md5`，也可在转换目录搜索“MD5 加密”。复用已安装的 @noble/hashes、@scure/base、字符编码模块、PapaParse 和转换工作台，不增加生产依赖。

- **文本**：默认 UTF-8，可选现有字符集、Hex 或 Base64 字节输入。小文本延迟 350 ms 自动计算；空串需手动点击计算。
- **逐行批量**：最多 10 MiB / 10,000 行，保留行号、空格、重复行和中间空行；末尾换行不增加记录。可选择跳过空行，提供当前项复制、CSV / JSON 导出，默认不导出原文。
- **文件**：选择或拖入最多 100 个文件，单文件最多 4 GiB；每次读取 2 MiB，在 Worker 中顺序增量计算。同名文件不合并，超限或读取失败只影响当前项。取消后保留已完成结果，未完成项标记取消。其他转换工具仍限 50 MiB。
- **HMAC-MD5**：消息和密钥分别指定表示，手动运行；允许空密钥，解码后最多 64 KiB。完成、失败、取消或离开工具后清空密钥。

单项提供 32 位大小写 Hex、16 位大小写兼容截取值及原始 16 字节摘要的 Base64。16 位值取完整 Hex 的中间 16 个字符，不等于完整 MD5。预期摘要支持完整 Hex、Base64 或明确的 16 位兼容模式，区分一致、不一致及格式错误；修改表示或预期值不重新读取文件。

MD5 是不可逆摘要，适用于校验和及旧系统兼容；不能用于密码保存或需要抗碰撞能力的安全签名。HMAC-MD5 仅作为兼容功能。没有解密、反查或暴力破解功能。输入、文件、密钥及结果均不上传、不保存。

实际测试、4 GiB 浏览器结果和截图见 [MD5 验收记录](./docs/md5-verification.md)。

## 办公工具（v1.3.3）

从左上角 LisTools 菜单选择「日常办公」，也可搜索名称直接进入。现有开发工具和转换子工具入口继续保留。

文本、图片、PDF、二维码和正则页先展示具体任务，提供可运行的本地示例；默认收起更多选项。示例会填入演示内容并运行真实处理，可继续修改输入。工作经历计算、面试邀请和 Offer 对比均已移除。

| 工具 | 功能 |

新增工具的按钮、说明和错误文案覆盖 50 种语言，简繁中文经过校对；其他语种包含自动翻译，结构完整性检查不等同于母语审校。切换界面语言保留输入和结果。人民币大写内容仍为中文，用户输入不自动翻译。

日期差默认不包含结束日，支持分别将今天设为开始日期或结束日期。工作日默认周一至周五，手动休息/补班日期覆盖默认周历，不附带在线节假日数据库。

图片默认清除 EXIF，JPEG 透明区域填白；达到目标大小可能需要用户允许降低分辨率。PNG 目标压缩可能减少颜色，无法达到时如实提示。图片最多 30 个、合计 100 MiB，单图最多 40 MP / 单边 16,384 px。PDF 最多 100 个文件、合计 100 MiB / 1,000 页；图片转 PDF 总像素最多 120 MP。加密 PDF 不支持，表单、书签、附件和数字签名的保留有限制。所有导出生成新文件。

计时器仅保存当前标签页的数字计时状态；关闭页面后不承诺后台提醒。其他输入、文件和结果不持久保存。

运行 `npm test` 检查核心逻辑，运行 `npm run test:browser` 构建并验证真实浏览器功能；后者需要 Chrome，非 macOS 环境可通过 `LISTOOLS_CHROME` 指定浏览器可执行文件。本轮移除记录见 [Offer 对比移除验收](./docs/remove-offer-verification.md)，此前交互调整见 [用途与交互验收记录](./docs/tool-usability-verification.md)，之前版本的验收证据保留在 [办公工具原始记录](./docs/office-tools-verification.md)。

## 大文件边界

采用开源编辑器现有的大文档与折叠实现，没有退回无法折叠的纯文本容器。格式化文本超过 50 × 1024 × 1024 个字符单元时会显示组件的大文件提示，用户可选择树形视图。该提示按字符长度判断，不按输入文件字节数判断，也不是性能保证。实际可处理大小依赖设备内存、结构和字符串长度。异常深的 JSON 仍受解析器递归限制。

输入要求为严格 JSON：不接受注释和尾逗号；重复键会报错，避免字段被静默覆盖。UTF-8 文件可直接导入。

## 网速、Cron、密码与正则

四项工具各有独立入口，全部复用统一侧栏和本地资源。新增界面提供中文、英文，其他语言回退英文。验收结果与环境限制见 [四类工具验收记录](./docs/four-tools-verification.md)。

- **网速测试**：仅点击开始后连接 `speed.cloudflare.com/__down` 与 `__up`，显示下载、上传、HTTP 空闲及负载延迟和抖动。轻量档计划约 14.4 MiB，标准档约 166.4 MiB；可以提前结束，开销、失败和重传可能增加实际流量。单请求最多 15 秒，整体最多 120 秒，取消或超时保留部分样本并标明未完成。样本不足不显示为零；轻量档可能不足以充分测量高速网络。关闭 SDK 的额外结果上报和凭证；公共服务仍会接收到连接 IP 及合成流量。无定位、运营商查询、UDP 丢包测试或自动节点切换。
- **Cron 表达式**：明确选择 Linux 五字段、含秒六字段或 Quartz 六／七字段，提供说明、逐字段校验、模板、可视化生成和时区日期预览。Quartz 支持常用 `? L L-n W LW nL #`，年份 1970–2099；日与周恰好一个 `?`，星期编号与 Linux 不同。复杂特殊字符组合明确拒绝。夏令时缺失时间跳过、重复时间取首次；服务器调度器的 misfire 等策略可能不同。仅计算表达式，不执行命令或安装定时任务。
- **随机密码与口令**：点击生成才运行；字符密码默认 20 位、支持 4–256 位、最多 100 条，支持字符类别、排除易混字符、自定义可打印 ASCII 字符集。类别要求使用完整候选重抽，不固定插入字符。词口令默认六词，使用本地 EFF 7776 词表和同一安全随机源；少数原词包含连字符。生成结果默认隐藏，修改参数或离开页面清空；只在主动点击时复制或下载。
- **正则工具**：使用 JavaScript 原生 RegExp，支持匹配高亮、捕获组、提取、替换、30 条可搜索规则与语法帮助。命名和编号组区分未参与匹配与空字符串；支持原生字符串替换占位符，不运行用户脚本。任务在 Worker 中执行，2 秒超时，可取消；超过 256 KiB 的文本手动运行。输入 10 MiB，表达式及替换模板各 16 KiB，匹配最多 10000 条、高亮最多 1000 处。截断时不执行完整替换；输出最多 100 MiB，仅预览前 1 MiB，复制下载使用完整结果。生成孤立 Unicode 代理项的输出明确报错，建议使用 u/v 或调整表达式，避免 UTF-8 导出时静默替换字符。

页面 CSP 将联网限制在测速页及两个固定端点，其他页面禁止连接；不增加网页访问权限或远程脚本。文本、密码、表达式和结果不保存到历史、URL 或本地存储，仅保留既有语言偏好。

## 工具菜单

Chrome 工具栏图标打开轻量菜单，选择工具后在新标签页打开。页面左上角 `Li LisTools ▾` 打开同一目录，普通点击在当前标签页切换；Ctrl/Cmd + 点击或鼠标中键在新标签页打开。点击当前工具只关闭菜单。全站工具仍使用左上角菜单；编码与转换页面另设左侧转换工具列表。

菜单支持中文、英文、工具别名和已翻译的页面名称搜索。编码与转换放在开发工具分组中，进入页面后通过左侧列表直接选择，也可搜索直达 Base64、Hex、JWT 等子工具，MD5 搜索结果合并为一个入口。↑ / ↓ 移动、Enter 选择、Esc 关闭，也可使用 Tab / Shift+Tab；中文输入法组合期间不拦截候选操作。关闭菜单清空搜索条件，保留当前工作区的输入、结果与运行任务。

弹窗只负责导航，不运行编辑器或算法，不新增扩展权限、后台脚本或运行依赖；所有页面入口来自同一份静态目录。新增菜单文案提供简繁中文和英文，其他语言使用英文回退。仅保存既有语言偏好，不保存搜索、输入或结果。
