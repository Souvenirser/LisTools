# LisTools v1.3.1 用途与交互调整

日期：2026-10-16。按确认后的方案精简功能，复用原有处理模块，没有新增运行时依赖、服务或扩展权限。

## 现在如何使用

| 入口 | 可以直接选择的任务 | 试用示例会做什么 |
| --- | --- | --- |
| 文本去重与提取 | 删除重复行；提取手机、邮箱或链接；批量替换；隐藏敏感信息 | 填入演示文字并真正处理，例如五行名单去重为三行；可修改输入后再次处理。 |
| PDF 合并与拆分 | 合并多份 PDF；每页拆分；提取几页；图片转 PDF | 加入本地示例文件并生成可下载的新 PDF 或 ZIP。重排、删除、旋转放在“更多选项”。 |
| 图片压缩与裁剪 | 压缩文件大小；修改宽高；裁剪图片；转换格式 | 在本机生成一张演示图并处理。尺寸和目标大小等设置默认收起；选修改宽高会展开。裁剪任务会打开裁剪编辑器。 |
| 二维码生成与识别 | 把文字/网址生成二维码；从图片读取二维码 | 使用 example.com 生成二维码，或把生成的二维码作为图片识别，展示原内容；不打开网址。尺寸和纠错设置收起。 |
| 正则测试（开发用） | 通过订单编号示例理解按规则提取 | 填入两条演示订单并提取 ORDER-1024、ORDER-2048。普通任务选择保留用户原文，仅明确点击示例才填入演示文字。 |

所有页面都能先选择具体任务，再放入文字或文件，最后复制或下载结果。示例为本地演示数据，调用实际处理流程；不会上传数据。文件大小、页数等既有处理限制仍有效。

## 移除与保留

工作经历计算和面试邀请已从导航、搜索、构建页面、对应源码、翻译资源和专用测试中移除；邀请生成专用的 `ics` 及不再需要的间接依赖也已删除。保留薪资对比。

19 个工具页、既有弹窗、MD5 快捷入口及其余功能保留。原测速的蓝色下载、红色上传和高分屏图表修复继续包含在本包中。历史完整包和历史验收记录保留，没有 Git 提交、远端推送或商店发布。

## 加载与包校验

下载 LisTools-1.3.1.zip（本地记录：`releases/LisTools-1.3.1.zip`），解压后在 Chrome 扩展管理页加载；已有开发目录可重新加载项目的 `dist/`。

候选包含 188 个文件、19 个工具页面和 1 个弹窗页面；ZIP 与 `dist/` 按文件列表及字节逐一匹配，退休页面和 `ics` 许可段已排除。具体大小、SHA-256 及与前一份完整包的比较见 包审计（本地记录：`docs/tool-usability-package.json`），校验文件为 SHA-256（本地记录：`releases/LisTools-1.3.1.zip.sha256`）。
