# LisTools 全站功能、视觉与操作体验精修实施方案

用户已批准本轮方案。沿用18工具页、MD5专用界面、37项转换、侧栏、主题和现有习惯。复用原生JavaScript/Vite、现有任务控制器和文件库，不新增依赖、权限、遥测、服务或持久化用户内容；不提交Git、不发布Release或商店。

## 必须交付

- MD5在pending开始本次批次，整体复制/CSV/JSON禁用，本次完成的单文件可复制。取消/失败只有当前批次完成项可导出；旧任务迟到响应无效。切类型丢弃数据之前确认，取消不改变模式或数据。HMAC离开清理不变。
- JSON读取采用版本保护；读取阶段可取消，晚到读取/错误不能覆盖编辑、清空、替换、离页。区分读取失败、UTF8错误及语法错误；拒绝导入保留有效原内容/结果。
- 隐藏字段错误有可见提示；显式提交展开details后定位，自动计算不展开/不抢焦点。只有一份可见错误，details切换同步反馈。
- 通知、正则弹层/高亮、对比错误/编号使用成对主题色。计时声音准备失败/权限等待不阻断计时，警告就近且稳定，成功/关闭/重置后清理。
- 编辑中的不完整数字前缀暂缓自动错误并失效旧导出；失焦/提交完整校验。单位折叠标题带数量，精度说明独立；抽签端点定位准确、UI结果带范围/重复条件；结构化导出不加标题。
- 计算器以表达式/角度/实际引用Ans或办公mode/输入作为同请求键；正则以原文/模式/flags/任务/替换/提取参数为键。同请求重算保留主结果/当前匹配/阅读位置，处理中导出受限，改变输入正确失效。计算器来源放在结果旁且不移动键盘。
- 手机转换、时间戳、Cron结果在屏外时提供显式定位，不自动滚动；PDF和图片结果旁提供返回参数/文件入口，不改变任务hash，不执行任务。
- 图片单个完整对比+有界批量结果列表，紧凑摘要/下载就近；体积减小/不变/增大/目标未达标分别说明。用户确认增大时仍保留实际输出，不自动回退原图，继续移除元数据。保留取消完成项/同名ZIP/裁剪保护。
- 测速8项指标使用明确翻译键；密码每行显示/隐藏有行号；收藏进入普通方向键遍历；弹窗最近入口随主题，保留排序/展开/滚动/版本/反馈。
- 保持JSON/对比阅读高度、PDF有效下载和页序、QR整数像素白边Unicode、文本预览与完整导出、时间戳DST/精度、37转换全部能力与地址。支持页仅样式复核，继续隔离构建排除并保留真实资源检查。

## 验收

先RED后GREEN，旧行为保护用例照常保留。新基线309单元与冻结旧产物637 Chromium（均为本轮重跑）。明暗×手机/短屏检查状态保持和错误可见性；同请求关键控件位移≤1 CSS px。检查320、390、768、1366、1440、1920、2560px及200%缩放；对比阅读高度1440x900≥440px、1366x768≥320px、窄屏每侧≥240px。

50语言结构/参数/动态标签与可访问名；中英重点、德文和阿语代表性界面。校验真实字节/PDF页序/图片尺寸/QR内容/完整复制。全量单元和Chromium、Edge/WebKit受影响工作流；Firefox/Chrome120/Safari/VoiceOver/物理触屏/微信按实际执行记录，不能冒充通过。

从最终Chrome ZIP解压验收断网冷启动、Worker、文件、下载和菜单；检查许可证/资源/零权限，ZIP与目录逐文件相同，生成SHA256与源码指纹。交付独立可加载目录、ZIP、截图、报告，保留工作区WIP和历史包，停止临时进程。
