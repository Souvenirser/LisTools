# LisTools v1.2.1 · 页面衔接与编辑体验修复

- 页面初始化完成后展示正确语言、任务与侧栏布局，减少旧文字和布局闪变。
- 增加轻柔主内容衔接，尊重系统减少动态效果设置。
- 短任务不闪过“处理中”；慢任务反馈延迟显示，取消与真实运行状态立即生效。
- JSON 输入新增“编辑”菜单（撤销、重做、全选）和“复制输入”，修复深浅主题光标。
- 保留现有功能、完整导出与 50 种语言，不新增依赖或扩展权限。

## 下载

`LisTools-1.2.1.zip` 为 Chrome 上传用 ZIP；本地使用请解压后加载扩展目录。附 SHA-256 校验文件。
