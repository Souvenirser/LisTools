# LisTools v1.2.9 · 折叠恢复与操作稳定性修复

- 修复 JSON／文本对比在空态、错误态收起输入后，展开入口消失的问题；保留鼠标、键盘展开和错误定位。
- 补齐直接编辑对比结果时的草稿保护，避免切换工具丢失仅存在结果区的文本。
- 修复日期差、工作日计算勾选“包含结束日期”时结果闪空、提示顶动输入及时间戳详情收起的问题；提示移入结果区，保留已展开详情。
- 计算器首行调整为 **AC →（ → ）→ 删除**。

保持原有功能、主题和导航；无新增依赖、扩展权限或用户内容存储。
