# LisTools 全站交互稳定与体验优化方案

日期：2026-10-26。基于当前工作树、用户连续反馈和真实浏览器复现制定。

## 1. 本轮目标

保留现有18个工具页面、MD5专用界面、37项转换能力、顶部导航、收藏、分类排序、展开同步、深浅主题及旧地址。让用户完成一次操作时，输入位置、按钮位置和阅读位置保持稳定；得到结果后可以直接判断下一步。

本轮先修已复现的缺陷。下一阶段的逐页精修以本方案为设计与验收依据，实施状态以本次验收报告为准，不把方案条目当作已通过测试。

## 2. 已定位问题与处理原则

| 现象 | 已实测原因 | 本轮修复方向 |
|---|---|---|
| 短屏工具切换仍出现侧栏位移 | 底部固定操作栏把整个布局及导航一并缩短61px，换页时滚动上限变化 | 桌面侧栏独立占满顶栏下方视口，固定操作只影响主内容 |
| 最近打开让侧栏经常重新排列、重绘 | 最近记录与收藏共处分类上方；任意偏好更新都会重建分类DOM | 最近记录移至顶部独立入口；历史／主题更新不重建分类；收藏和分类保留浏览位置 |
| 编码参数一上一下、标题重复 | 方向标签和按钮重复；所有参数都套同一种纵向字段结构 | 编码／解码与“文本字符集 UTF-8”并排，保留读屏名称；短参数同行、长输入自然排列 |
| 转换工具目录分类难辨 | 小号灰色标题与工具连续排布 | 八组采用独立边界、标题底色、组间距、缩进；分类标题随组滚动，搜索保留分组 |
| 日期结束项为空、报错后错位 | 结束项未初始化；字段底部对齐，错误使单列变高 | 日期差／工作日两端默认本地今天；年龄起点空白；字段与错误分行并顶部对齐 |
| 同一错误出现两遍 | 全局横幅与字段提示同时可见 | 字段错误就近显示；全局保留辅助技术播报与状态；无字段目标的错误继续使用横幅 |
| 深色单位下拉白底白字 | 上游高亮选择器及颜色变量保留浅色默认值 | 统一Choices主题变量，检查选中、悬停、键盘高亮和次级文字 |
| 勾选全部单位先清空再回来 | 输入失效后等待350ms重算，并再次触发自动执行 | 仅展示范围变化同步计算；保留主等式；取消重复的延迟执行 |
| 计时器开始、暂停、继续跳动 | 运行状态强制收起／展开时长设置，按钮文案宽度也变化 | 设置展开由用户控制；时间与操作在前；按钮轨道、状态位置稳定 |
| 文本执行按钮与编辑区来回移动 | 状态出现让操作区增高；手机处理中隐藏主按钮 | 保留状态行和主按钮位置，处理中禁用；取消始终可达 |
| Cron重算时结果区闪空、缩短约650px | 每次请求先发idle再pending，页面立即清除结果展示 | 有效请求直接进入pending；相同请求重算保留展示并禁用导出；变更、取消和错误使结果失效 |
| 长密码文字与眼睛按钮重叠 | 眼睛绝对定位在输入框内 | 每条结果上方放置显示／隐藏和复制；值区域保留完整宽度 |
| 对比重算后手机自动滚到第一处差异 | Worker在完成后自动选中第一处差异，并触发编辑器滚动 | 相同内容重算保持当前差异、选区与滚动；首次对比和主动差异导航保持原行为 |
| 200%文字放大后320px顶栏溢出 | 新最近入口与品牌、搜索、设置被限制为单行 | 顶栏按实际内容自然换行，控件不缩小 |
| 长内容工具重跑闪烁、按钮移位 | pending清空预览、销毁编辑器或隐藏工具栏 | 保留成功展示的阅读空间；忙状态明确，复制下载失效；不重建无关控件 |

## 3. 全站统一设计

### 3.1 导航稳定

- 顶部保留品牌、全局搜索、最近打开、设置；手机使用有可访问名称的紧凑按钮。
- 最近打开默认收起，点击后展示最近五项；页面与扩展弹窗共用既有记录。不占用分类列表高度。
- 左侧保留收藏和四个分类。历史记录、主题和参数偏好变化不重建分类；收藏、排序、分类展开仍按用户操作更新。
- 当前工具、悬停和键盘焦点有不同视觉反馈；名称单行，中文完整显示，其他长语言可查看完整名称。
- 搜索、菜单和弹层退出后回到原触发控件；侧栏滚动与主内容滚动独立。
- 保留原生多页面架构。本轮针对视觉重排与重复渲染，不引入SPA迁移或iframe导航壳。

### 3.2 布局层级

顺序固定为：工具名称与一句用途 → 任务及必要参数 → 输入／预览与执行 → 结论／明细 → 复制下载 → 使用说明。

- 长编辑器利用剩余空间，保持内部滚动、末尾可达和完整导出。
- 小表单使用合理最大宽度，输入、主结论相邻；结果卡片按内容增高。
- 文件页无文件时突出导入；有文件后突出当前对象、必要参数与处理动作。
- 折叠高级设置与长说明；影响当前执行的选项和限制直接可见。
- 短标签、切换按钮、单位与短选择器在同一控制行；长标签允许换行，字段仍对齐。
- 当前动作只保留一个蓝色主按钮。每个按钮使用具体动作名称。

### 3.3 稳定状态规则

| 状态 | 用户看到什么 | 操作规则 |
|---|---|---|
| 初次空态 | 简短下一步说明 | 隐藏无用导出；主动作不可用时说明原因 |
| 输入有效 | 当前输入与必要参数 | 手动／自动执行规则保持原工具语义 |
| 正在执行 | 固定位置的进度与忙状态 | 主按钮原位；支持取消的任务显示取消；有效性未确认的导出禁用 |
| 相同内容重复执行 | 已有展示和阅读位置保持 | 不闪空、不先缩短卡片再撑开；完成后更新数据 |
| 输入或关键参数改变 | 明确需要更新的状态 | 旧结果失效，防止复制错误数据；自动计算保持防抖及输入法保护 |
| 成功 | 首先显示结论，再显示明细 | 导出跟随结果；不强制滚动 |
| 零结果 | “未找到”及实际计数 | 属于有效结果，不显示为执行错误 |
| 失败 | 就近说明原因与修正方法 | 字段错误不挤歪相邻输入；技术原文按需展开 |
| 取消／部分完成 | 已完成项和取消范围明确 | 迟到消息不能恢复旧任务；只允许下载完整且有效的完成项 |

自然展开高级设置、查看结果和主动跳转属于用户有意操作。无主动布局变化的开始、暂停、继续、重复计算，关键控件位移目标不超过1 CSS px。

### 3.4 视觉与可读性

- 正文、按钮与输入16px；辅助说明至少14px；正则模式18px；长内容使用16px等宽字体。
- 普通触控目标至少44px；辅助桌面按钮保持既有尺寸。
- 桌面卡片内边距24px、手机16px；相关控件12px、区域24px；紧凑参数行通过关联关系分组。
- 深浅主题的下拉展开、已选、高亮、禁用、焦点、提示和错误都单独检查。
- 普通文本对比度至少4.5:1；状态同时使用文字，避免仅靠颜色。
- 保留蓝色品牌、计算器彩色按键、测速蓝色下载／红色上传及七档图。
- 状态区保留适当空间；长错误自然换行，不通过裁掉文案或缩小字号维持表面稳定。

## 5. 本轮之外的文案与流程精修

这些条目在当前缺陷修复通过后按小批次审阅实施，不自动扩充工具能力：

1. 每页用途说明改成普通用户能理解的一句话；ISO、HTTP等技术口径进入相关说明，关键限制保留可见。
2. 系统复核所有下拉、错误、复制名称和下载提示，补齐既有英文回退及不一致术语；50语言结构检查与人工语言审校分开记录。
3. 文件页统一“等待添加、可处理、处理中、已完成、部分完成”的主入口；结果标题、下载与实际处理范围相邻。
4. 长值工具统一预览说明、完整复制与导出路径；密码可进一步评估明文多行只读展示，默认遮罩与隐私边界保持。
5. 对真实手机软键盘、触屏排序、VoiceOver、Firefox／最低Chrome／Safari安装补齐环境覆盖；启动失败与未执行单列。

## 6. 实施与验收方法

### 实施顺序

- P0：本轮已复现缺陷，先写失败用例，最小修复，再检查同类组件。
- P1：合并共享改动，运行全量单元和打包页面测试，检查两主题、长语言与真实文件；补齐代表性成功／失败／运行截图。
- P2：按上一节做文案、文件流程和兼容补测，每批有独立验收，不再整站反复重排。

### 硬性通过条件

- 明暗主题×桌面1440×900／1366×768×手机390×844，另查320／768／1920／2560px。
- 重复运行、开始暂停、展开结果的每一帧，关键输入、按钮和阅读区域位移≤1px；没有短暂清空、隐藏按钮再恢复或丢失焦点。
- 输入实际变化后旧结果不能继续复制下载；相同输入重跑可保留展示，但明确忙状态。
- 字段错误不改变同一行其他标签、输入和快捷按钮的对齐；没有重复可见错误。
- 手机长编辑器单侧≥240px，首屏露出≥120px当前输入；数据量增加不把编辑器撑成数千像素。
- 下拉检查普通、选中、悬停、键盘高亮、无匹配和禁用，不只做关闭态截图。
- 延迟真实Worker响应验证处理中，不用假结果替代算法；核对文件实际字节、页数／页序、图片尺寸、完整文本和复制内容。
- 语言、主题、窗口变化不清空输入，不重建无关编辑器；取消、超时、迟到消息和无效导入受保护。
- 最终验收从ZIP解压目录运行，绑定源码及包SHA-256；目录与ZIP逐文件一致，零新增权限／依赖；测试进程结束回收。

### 交付

更新源码、本地可加载目录、Chrome ZIP及SHA-256、前后截图、测试日志、已执行范围和兼容缺口。保留原工作区修改与全部历史包。Git提交、Release及商店上传继续等待明确指令。
