# LisTools v1.2.7 · 常驻工作台与切换稳定性修复

- 顶栏、侧栏常驻，目标工具准备就绪后替换内容，修复快速切换时的瞬间空白。
- 连续点击以最后选择为准；慢加载和失败时保留当前工具，并提供重试入口。
- 保留旧地址、任务深链接、前进后退、搜索预选和已有输入保护。
- 修复转换文本在历史导航中丢失、语言切换后标签页标题错误、专注模式高度及根地址启动问题。
- 保留转换普通文本与阅读状态，继续执行 HMAC 密钥和密码的离页清理。
- 无新增依赖、扩展权限或用户内容持久化；未发布支持页继续排除安装包。
