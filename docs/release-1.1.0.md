# LisTools 1.1.0 发布验证

2026-10-21。正式版本统一为 1.1.0；此前 1.2–1.4 编号仅用于本地开发候选包。

## 本次功能

- 18 个独立工具页及统一工具栏菜单，保留 JSON、对比、时间戳、编码转换、MD5、测速、Cron、密码与正则工具。
- 计算器支持标准／科学模式、彩色按键、DEG／RAD、80 位高精度计算、Ans 和页面内历史。
- 日期计算支持分别将今天设为开始日期或结束日期；二维码、图片、PDF、文本、单位、人民币大写、抽签与计时继续提供本地处理。
- 测速下载采用蓝色、上传采用红色，曲线适配高清屏；下载和上传分别显示步行、自行车、摩托车、汽车、高铁、飞机、火箭七档本地 SVG 图片评价。
- 工具页移除固定宽度上限，宽屏工作区使用可用宽度，窄屏及 RTL 自适应。
- 50 种本地语言资源、带国旗和搜索的语言选择器、Cron 本地化及 GitHub 问题反馈入口。
