# LisTools v1.3.3 更新提示候选

工具栏弹窗左下角在确认有新版时显示「更新」按钮，其他状态显示当前版本。

## 安装与更新

- GitHub 下载包使用 `LisTools-1.3.3.zip`。下载并解压，替换原扩展目录，再到扩展管理页点 LisTools 的「重新加载」。
- Chrome 应用商店使用 `LisTools-Chrome-Store-1.3.3.zip`。商店安装用户收到 Chrome 的新版下载通知后，可点「更新」打开扩展管理页。保存内容并关闭打开的 LisTools 页面后，Chrome 会在扩展空闲时完成安装。
- 两个 ZIP 的校验文件为 `SHA256SUMS-1.3.3`。在下载目录运行 `shasum -a 256 -c SHA256SUMS-1.3.3` 检查文件完整性。
