## 功能与口径

| 工具入口 | 已交付能力与边界 |
| --- | --- |
| `calculator.html` | math.js BigNumber 80 位计算精度，结果显示 24 位有效数字；显示舍入时标记 `≈`，复制保留计算结果精度。支持四则、括号、百分比、乘方、开方、常用函数、办公公式、键盘与页面内记录。表达式节点白名单，禁止赋值及属性访问，独立 Worker 可取消并在超时后终止。 |
| `dates.html` | 日期差、年月日历差、加减年月周日、年龄/周年日/目标日期及工作日。纯日期采用 Temporal，默认不含结束日；月底按目标月有效日期约束。手填休息及补班日期覆盖周一至周五，冲突时补班优先。 |
| `qr.html` | 文字和 Unicode 内容生成 PNG/SVG，尺寸、纠错设置，文件、拖入与粘贴识别；每张静态 PNG/JPEG/WebP 返回一个识别内容，不自动访问链接。 |
| `images.html` | Cropper.js 裁剪、旋转、翻转，指定尺寸或比例缩放，JPEG/PNG/WebP 转换和压缩，顺序队列、逐张或 ZIP 下载。裁剪后再缩放和编码，朝向通过浏览器图片解码处理，默认移除 EXIF，透明区域转 JPEG 时填白。目标大小未达到会显示实际值，降低分辨率需要显式选择。 |
| `text.html` | Unicode 字符簇、当前语言分词、行与 UTF-8 字节统计；复用现有行处理、命名和换行转换；字面替换、邮箱/电话/链接提取、可选信息类型脱敏、TXT 导入导出。提取在正则 Worker 中执行，不用带首尾锚点的校验表达式替代提取规则。 |
| `units.html` | 长度、面积、体积、质量、温度、速度、压力、能量、功率、角度，支持中文/英文别名、来源目标交换及多目标结果。温度含偏移，非同类转换拒绝；复制标准无千分位数字。原有位/字节和固定时长转换保持原实现。 |
| `money.html` | 数字字符串经 Decimal 舍入为两位小数，再用 nzh 输出简繁人民币大写；支持零、负数、大金额、标准金额和千分位分别复制，显示舍入前后金额。 |
| `pdf.html` | PDF 合并、拆分 ZIP、页码范围提取、指定页序重排、删除、旋转，以及有序图片转 A4/原图尺寸 PDF。pdf-lib 操作结构，不引入 PDF 渲染器。拒绝加密 PDF，不启用 `ignoreEncryption`。表单、附件、书签和数字签名保留限制在操作前提示，输出新文件。 |
| `draw.html` | 忽略空行、保留重名条目，抽取、洗牌、按组数或组内人数分组，范围随机整数及可选无重复；显式去重、复制、TXT/CSV。使用浏览器密码学随机数、Fisher–Yates 与拒绝采样。 |
| `timer.html` | 倒计时快捷/自定义时长、暂停继续、重置，秒表及分段复制；按截止时间和累计耗时恢复。当前标签页会话可跨刷新及工具页切换恢复，前台恢复重新核时。仅用户开启后尝试播放提示音，关闭页面后不承诺后台提醒。 |
| `salary.html` | 最多五个同币种税前方案；保障现金为月薪×保证月数＋固定年度补贴，预计现金另加浮动奖金，首年现金再加一次性现金。相对首个方案比较，零基准涨幅显示不可计算；表格复制、CSV 导出。 |
| `interview.html` | 公司、岗位、候选人、时间、时区、时长、地点/链接、联系人及准备事项生成可编辑邀请，下载 UTC 起止的 `.ics`。复用现有时区解析，拒绝夏令时不存在或重复的本地时刻。导出普通 PUBLISH 日程，不添加自动邀请收件人，不自动发送。 |
| `experience.html` | 月/日两种精度独立保存当前页面输入，包含起止月份或日期，支持多段、至今、名称备注。显示每段、原始累计及重叠区间去重结果；列出当前设备日期基准。日精度以天数为主，不用除以 365 推算精确工龄。 |

图片输入最多 30 个、合计 100 MiB，单文件 50 MiB，单图 40 MP、单边 16,384 px；输出合计最多 100 MiB。PNG 目标压缩可能量化颜色。动画格式不承诺保留动画。PDF 最多 100 个输入、合计 100 MiB / 1,000 页；图片转 PDF 总像素上限 120 MP。上述预算用于限制页面内存，不能作为任意设备都能达到的性能保证。

## 语言、隐私与验收范围

新增 14 个命名空间（共享＋13 工具），每种语言 453 个键，覆盖现有 50 种语言。自动检查键集合、非空文案、插值参数和翻译标记；浏览器遍历全部语言验证输入/结果保留。简繁中文已校对，Yoruba 文案另行检查；其他语种包含自动翻译，尚未全部经过母语审校。已检查[中文计算器](./office-calculator.png)、[中文薪资](./office-salary.png)、[繁体金额](./office-money-zh-Hant.png)、[日文日期](./office-dates-ja.png)、[德文 PDF](./office-pdf-de.png)及[阿拉伯文邀请窄屏](./office-interview-ar.png)截图，未发现界面溢出。原生文件选择控件及系统对话框使用浏览器/操作系统语言。RTL 布局检查不等同于阿拉伯语母语审校。

扩展 `permissions`、`host_permissions` 均为空，没有后台脚本和 `unsafe-eval`。所有新工具页的 `connect-src` 为 `'none'`，依赖、字体、语言和 Worker 均随包加载。原测速页保留已有两个固定端点及主动启动策略。没有接入遥测或上传文件。

语言偏好沿用既有持久化；计时器仅向当前标签页会话保存必要数字时间状态。计算历史、文本、名单、薪资、邀请、图片和 PDF 不写入持久存储、URL 或日志。切换语言不会清空工具输入、结果或文件队列；用户内容不自动翻译。

## 包体变化

与保留的 `LisTools-1.2.1.zip` 比较，ZIP 从 1,640,089 字节增至 2,595,889 字节，增加 955,800 字节（58.28%）；展开后从 4,912,659 字节增至 7,983,743 字节。这是整个当前工作树构建结果的比较，包含既有修改，不是仅对 13 项工具的隔离测量。

最大的 JavaScript 块约为 JSON 666 kB、重任务 Worker 651 kB、单位换算 615 kB；QR 页面约 158 kB。Vite 对超过 500 kB 的块保留体积提示，构建成功。工具注册表只保存元数据，菜单不提前导入这些计算和文件处理库；相应页面或任务使用时才加载。
