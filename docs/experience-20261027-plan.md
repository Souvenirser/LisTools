# LisTools 1.2.0：操作与视觉精修

以当前完整工作树为基础，保留全部用户修改、18 个页面、MD5 专用界面、37 项转换功能和 50 种语言。新增依赖和权限为零；默认不提交或发布。

1. 共享任务入口把相同选择视为无操作；首次路由初始化和真正切换继续使用既有回调。验证密码、PDF、大文本结果、运行中任务及滚动保持。
2. 搜索用固定白名单直达提取类型、行处理、大小写和 Base64 方向；只预选，不执行，不携带用户内容；保留旧地址、前进后退和唯一选中。
3. 紧凑参数与状态行、对齐文本阅读区；手机保留有界状态区和首屏阅读高度。MD5、日期空态隐藏无效导出；文件工具保留一个主要导入入口。
4. 精修计算器精度说明、日期标签、单位说明、抽签输入标题、计时器比例、二维码设置摘要、测速首次说明和当前时间复制名称。JSON、对比、金额和密码的既有合理布局通过回归保护。
5. 独立快照排除未发布支持页，原工作树的真实资源检查保持有效。最终 ZIP 解压后执行无热更新、实际扩展离线、完整下载和菜单验收。

验收：单元、Chromium 全量、Edge/WebKit 相关工作流；七种宽度、明暗主题、长内容、320px 重排、200% 浏览器缩放。未执行环境和翻译初稿审校边界必须明确记录。
