# LisTools v1.2.3 · 日期结果与长内容阅读修复

## 本次更新

- 日期计算将标签、日期、星期和计算条件分层展示，避免大字整句导致日期断行。
- 日期结果支持对应日期时间、Unix 秒／毫秒时间戳，默认设备时区与午夜；复用可搜索的国旗时区选择器，支持毫秒时间。UTC 与带偏移 ISO 格式可展开查看。
- 日历日期运算与时间戳派生分开；夏令时重复／缺失时间保留日期结果并提示修正时间或时区。日期输入及返回值统一为 0001—9999 年，越界明确报错。
- 长密码使用只读横向阅读区，增加左右查看按钮、溢出提示和实际字符数；复制与下载仍使用完整原值。重新生成结果恢复默认遮挡。
- 单位换算分开来源及目标数值，长结果不再无限增高；计算器补充左右溢出提示并保留完整值复制。
- 补充现有 50 种语言的相关标签与可访问名称。保留现有工具、转换能力及本地处理规则，无新增依赖和扩展权限。

## 下载与安装

附件 `LisTools-1.2.3.zip` 可上传 Chrome 开发者后台；本地使用请解压，在扩展管理页加载直接包含 `manifest.json` 的目录。附 SHA-256 校验文件。GitHub 自动生成的 Source code 是源码，不是已构建扩展。

## 验证边界

**按用户要求，本次发布未重新测试。** 本次只更新版本、执行生产构建并核对源码、ZIP、版本及附件，既有候选验证不作为 v1.2.3 的新测试结果。50 语言翻译初稿及结构覆盖不等于完整母语审校。
