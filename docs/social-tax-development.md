# 五险一金与个税实施记录

实施依据：2026-11-03 用户批准的《LisTools 五险一金与个税计算器开发方案》。

## 不变量

- 20 城与自定义；insurance / tax 两个入口；工资、奖金、年度工资估算。
- 离线，零新增依赖和权限；工资与结果不持久化，不进入地址、日志或反馈。
- 复用 Decimal、Choices、Temporal、PapaParse、导航与表单组件；50 种语言。
- 当前工作树及历史包保留，不提交 Git、不发布、不覆盖 v1.2.4。
- 未核验、缺失或过期政策不得伪装成有效参数；缺失项必须显式补充。

## 实施切片

1. 政策来源与纯计算核心：基数分项、舍入、固定额、税前扣除、累计预扣、奖金、年度口径；先 RED 再 GREEN。
2. 两个入口与共享表单：城市、分项设置、三种个税任务、错误定位、完整导出、结果保护。
3. 50 语言、搜索、许可证与维护工具。
4. 完整单元与受影响浏览器、主题和尺寸检查；隔离生产快照、ZIP、哈希、清单和报告。

## 验收重点

政策按险种和月份匹配；实际基数不被工资覆盖；未知不等于零；现金扣款与可扣除额分离；生育合并不重复；公积金双方独立；年度费用 60000；首次就业需确认；奖金比较采用同一工资基线；真实预缴才提供退补。
