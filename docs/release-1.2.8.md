# LisTools v1.2.8 · 五险一金与个税易用性改进

- 工资个税默认选择北京，按工资自动估算个人五险一金；公积金采用所选城市规则允许的最高普通比例，可调整，各险种与公积金分别应用基数上下限。
- 城市选择只显示城市名，个人缴费预览区分社保和公积金，保留实际基数覆盖、手填缴费与工资条核对。
- 直接展示全年每个月的工资、个人缴费、预扣个税、到手工资及合计，复制和下载包含完整明细。
- 改善年度同薪、扣除助手及累计预扣流程，补充不合理金额校验、模式草稿保护和附税部分成功反馈。
- 修复 WebKit 工资条核对首次点击失效、混合逐月明细漏显示现金扣款、补充公积金与城市规则衔接问题。
- 暂不展示“请作者喝咖啡”入口，保留支持页源码，安装包排除支持页。

## 政策与试算范围

城市参数按适用月份匹配。参考参数继续明确标为参考试算；本版不宣称已完成 20 城全部官方政策核验。估算不等同于实际工资单或正式纳税申报。
