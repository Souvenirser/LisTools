# LisTools v1.2.2 · 缩放与工作区布局修复

- 修复正则及共享编辑器正文中的蓝色焦点横线，保留清晰光标和外框提示。
- 1200 CSS px 以上保留文字侧栏，空间不足时使用完整文字菜单，避免放大后分类与工具难以辨认。
- 修复时间戳当前时间卡片被压缩、转换结果相互遮挡的问题。
- 转换目录支持分类折叠及记忆；搜索临时展开匹配分类，清空后恢复，不再由吸顶标题遮住工具。
- MD5 输入与结果独立滚动，搜索移至输入标题栏，展开其他格式不再拉长左侧空白。
- 计算器标题、说明和历史移入侧面信息栏；收紧主面板，让标准键盘更容易完整显示。
- 修复日期／Cron 任务栏居中，以及短屏设置中语言下拉越界和滚动定位。
- 保留现有工具、37 项转换、50 种语言和本地处理规则，不新增依赖或扩展权限。

## 下载与安装

附件 `LisTools-1.2.2.zip` 可上传 Chrome 开发者后台；本地使用请解压并加载目录。附 SHA-256 校验文件。GitHub 自动提供的 Source code 是源码包，不是已构建扩展。

## 验证边界

按用户要求，发布 v1.2.2 时不重新运行测试，仅更新版本、构建及核对发布文件。紧接本次发布前，同一功能修复的 1.2.1 候选已完成 337 项单元、784 项 Chromium、118 项 Edge／WebKit 回归；7 个重点入口完成原生 100%、125%、150%、200% 缩放，另有全站 532 个响应式状态及最终 ZIP 的离线扩展检查。这些是候选证据，不宣称 v1.2.2 新运行了测试。

未验证：Firefox、最低 Chrome 120、Safari 原生扩展安装、VoiceOver、物理触屏及微信实机。原生缩放使用 Chrome 扩展标签页缩放 API；WebKit 测试不等同 Safari 安装验收。支持页继续排除生产产物。本次仅发布 GitHub Release，不提交 Chrome 商店审核。
