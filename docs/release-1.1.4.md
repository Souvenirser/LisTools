# LisTools 1.1.4 发布验收记录

本版修复菜单分类状态和弹窗固定高度。复用已有菜单、localStorage 和分类 ID，没有新增运行时依赖、权限或联网服务。原有工具、排序、搜索和计算功能保留。

## 行为与原因

- 首次使用时，页面左上角菜单与扩展弹窗的四个分类全部收起。
- 分类展开和收起立即保存到同一份偏好；同一扩展实例中的页面和弹窗实时同步，重开、刷新、切换工具及浏览器重启后恢复。
- 搜索和语言切换保留状态；排序中的临时展开独立处理，取消或恢复默认顺序不会清除正常浏览的展开偏好。
- 只保存稳定分类 ID，忽略未知和重复 ID；存储不可用时在当前页面内保留，不影响工具使用。开发服务器与已安装扩展属于不同来源，各自保存偏好。
- 弹窗改用自然文档流，全部收起时按内容缩短；展开后最高 560px，仅列表内部滚动，页脚跟随内容。

原菜单每次渲染都会强制展开弹窗前两个分类或当前工具分类，没有保存正常浏览的状态。现在点击时同步记录展开意图，处理其他页面的 storage 事件，避免快速搜索或关闭时延迟 toggle 事件丢失。原 html/body 固定高度和菜单固定定位导致收起后留白，本版去除这两处约束。

## 验证

- 变更前 296 项单元测试通过；新增浏览器用例先复现默认展开和固定 560px 高度问题。
- 1.1.4 公开源码全量单元测试 **299 项通过，0 失败**。
- 最终 Chrome 包预览：Chromium、Edge、WebKit **206 项通过，1 项跳过，0 失败、0 不稳定重试**。涵盖展开同步、持久化、排序、搜索、全部工具和 37 项转换入口、内容保护、语言和窄屏。跳过项为 WebKit 不适用的触屏调度测试。
- 实际 Chrome **149.0.7827.55** 加载最终目录并断网：首次收起、双向同步、显式收起、重开、刷新和浏览器进程重启恢复通过；没有页面错误和外部请求。
- 中文 popup 文档实测：全部收起 **417px**，全部展开 **560px**；列表内部滚动，页脚直接跟随内容。
- 50 种语言键和参数检查随全量单元通过；本版没有新增界面文案。

Firefox 和 Chrome 120 在上版验收中启动失败，本次未重新验证，不计通过。WebKit 页面验证不代表 Safari 扩展安装；无头环境未验证原生工具栏弹窗生命周期，测量的是扩展内 popup 文档。
