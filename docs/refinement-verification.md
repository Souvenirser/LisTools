# LisTools 1.2.0 本地精修候选验收报告

本轮在现有1.2.0工作树上精修18个实际工具页面、MD5专用界面、37项转换能力、页面菜单和扩展弹窗。沿用原有设计及算法；没有新增运行时／开发依赖、权限或服务。未提交Git、发布Release或上传商店。

## 用户反馈与修复

- 展开侧栏改为256px，紧凑侧栏保持64px。中文工具名保持16px、单行完整显示；其他长语言以单行省略和完整可访问名称／title保留信息。
- 收藏／取消收藏保留当前可见行及焦点。切换工具恢复侧栏浏览位置；只保存工具／分类ID、相对位置及滚动值，键为`listools-menu-view-v1`，不保存用户内容。删除最后一个收藏时将焦点交给附近可见控件。
- 常驻侧栏隐藏重复搜索／排序条，顶栏搜索或Ctrl／⌘K进入搜索，设置进入排序；结束排序后关闭覆盖层并返回可见设置按钮。原有展开状态同步、默认收起、排序和唯一选中保持。
- PDF导入锁保护首批文件，重复拖放明确提示读取中，完成后可以追加；读取完成清除过期状态，读取页数仍保留有效下载。
- 密码逐条显示独立，全局显示后隐藏第二条不影响其他行；只更新必要行，保留键盘焦点和离页清理。
- 图片Worker沿用现有任务编号，新增可选逐项完成事件。同名输出先去重再发出，取消保留已完成下载，最终结果按fileId合并；主区域提前展示前后对照。移除／清空未保存裁剪需要原有确认，取消保持选区。
- 抽签无变化去重不清空结果；预览限制100组及1 MiB UTF-8预算，复制／TXT／CSV仍使用完整结果，emoji不会被截成无效字符。
- 测速按已有原因码翻译网络及启动错误，完成后设置收为摘要；蓝色下载、红色上传和七档评级保持。
- 转换目录按主区实际1280px判断，目录与弹层采用同一条件。转换／正则收紧控制区，保留阅读高度；空闲取消及无效结果导出隐藏。
- 计算器手机键盘保持首屏且成功、错误、输入切换不跳动；计时器时间和主操作同屏；单位手机来源／交换／目标连续；金额标准值与大写靠近。
- 时间戳信息收紧，复制名称含格式上下文；Cron当地时间优先，UTC／偏移展开查看，ISO复制常驻；二维码导入区支持键盘、拖放及粘贴。
- 额外自测发现长二维码的分数像素绘制问题：预览使用整数码元，缩放只重绘已有矩阵，不重新生成内容；PNG按所选尺寸单独绘制，SVG保持原输出。验证实际预览及320×320下载，最小四码元白边保留。
