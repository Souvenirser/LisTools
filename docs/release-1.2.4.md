# LisTools v1.2.4 · 稳定性与窄屏体验修复

## 本次更新

- 正则规则库在首次可见前准备内容，JSON 编辑菜单提前定位，减少首次打开的空壳与跳变，兼容“减少动态效果”。
- 文本链接提取正确处理外层括号，保留地址内部的平衡括号、查询串、片段及百分号转义；不修改原文。
- 相同条件重复计算日期保留结果节点、选区和阅读位置；真实修改仍使旧结果失效。
- 修复日期结果的描述列表结构和时区描述引用，使用明确的结束／参考日期标签；时间与时区按可用宽度排列，完整显示毫秒。
- 日期和查找替换的长标签共享输入行，错误和“今天”按钮独立排列；修复 320px 查找替换输入裁切。
- 修复手机底栏中隐藏状态播报区的滚动告警，保留可见长状态的正常滚动。
- 保留全部现有工具、37 项转换、50 种语言、计算规则、菜单排序、收藏及展开同步；没有新增依赖、扩展权限或用户数据存储。

## 下载与安装

附件 `LisTools-1.2.4.zip` 为 Chrome 上传用包，根目录直接包含 `manifest.json`。本地使用请解压，在扩展管理页加载该目录。附 SHA-256 校验文件。GitHub 自动生成的 Source code 为源码，需先安装依赖并构建。

## 验证边界

本次版本更新前，功能候选已通过 342 项单元测试、808 项 Chromium 回归、43 项 WebKit 定向检查，另完成 100%／125%／150%／200% 原生 Chrome 缩放、实际扩展离线 Worker／文件往返和工具栏弹窗检查。上述浏览器记录属于 1.2.3 独立候选的同一运行时代码，不能称为 1.2.4 的新浏览器全量测试。

本次发布重新运行单元测试、执行生产构建，并核对发布源码、版本、Manifest、资源、许可证、ZIP 和 SHA-256。Firefox、Edge、最低 Chrome 120、Safari 原生扩展、VoiceOver、物理触屏及微信实机未完成本次发布验收；50 语言结构检查不等于母语审校。

支持页继续只保留在工作区，排除发布源码和安装包；真实资源检查未在工作区关闭。历史包保留。本次仅提交 GitHub 并发布 Release，不提交 Chrome 商店审核。
