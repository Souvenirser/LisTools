## 已实现与验证的变化

| 项目 | 实现与证据 |
| --- | --- |
| 默认填写 | 工资与个人五险一金均要求明确填写，空值不等同于 0。普通预估默认按个人缴费全额可扣除，旁边与结果均说明假设；特殊缴费显式启用后单独填写可扣除额。 |
| 工资到手 | 原 `#wage` 保持，年月直接选择；到手工资、本月个税、个人缴费和税前工资优先，累计与税率进入计算过程。2026-11、月薪 20000、个人缴费 2000、从 1 月同薪，得到个税 1300、到手 16700。 |
| 扣除助手 | 子女、婴幼儿、赡养老人、住房与学历继续教育分别设置；先编辑草稿，只有“使用此扣除额”替换合计。关闭不改有效扣除或结果，手工合计优先，住房为单一互斥选项。资格与来源可展开，不收集姓名、证件或地址。 |
| 核对工资条 | 保留实际累计模式；收入、已扣税等未知历史金额要求核实，不静默填 0；基本减除费用推导并允许受限手工调整。普通、首次取得工资、6 万元简化预扣均保留，特殊口径需确认。 |
| 年度输入 Bug | “每月相同”直接构造 12 个月计算输入，不再要求先填充。20000 月薪、2000 个人缴费直接得到全年税前收入 240000。 |
| 年度草稿 | 同薪与逐月草稿分别保留；首次可承接有效同薪输入，后续不覆盖逐月编辑；重新填充使用现有覆盖确认。缺政策不生成零缴费。 |
| 年度扣除与退补税 | 新增可选 `annualSpecialDeduction`，仅在年度应纳税额扣一次，不乘 12，不影响月度预扣；医疗另填。仅填写实际已扣税后显示退补税，使用正金额与明确方向。 |
| 奖金 | 默认仅算税后奖金，比较要求不含该奖金的年度基础。条件承接是显式操作，保留同年及工资范围；年中入职、应税调整与千分位金额均进入一致的比较基础。奖金核心仅新增可选的年度应税调整字段，旧调用保持默认 0。 |
| 结果与下载 | 展示、复制及下载读取同一计算结果与条件；技术数据保留原始值。逐月表与完整 TXT/CSV 导出均验证，未把未知政策月份显示为 0。 |
| 稳定性 | 修复失焦时移动操作区域导致首次点击丢失；相同位置不再重挂节点。同条件重算保留结果节点。助手与城市公积金控件的重复 ID 已分开；清空年月时错误指向可见输入。 |

主要源码改动位于 `src/tax.js`、`src/tools/payroll/tax.js`、`tax-input.js`、`deduction-assistant.js`、`style.css` 及 `src/locales/`。计算仍使用现有 Decimal 和累计预扣核心，没有新增计算服务或状态框架。

## 无障碍观察与未验证边界

- **待人工确认：**在 iframe 中开启原生模态对话框后，对整页运行 axe 会报告宿主文档 `page-has-heading-one` 最佳实践观察。活动对话框有命名标题，背景由原生 modal 隔离；本轮对活动对话框单独扫描并检查 Esc/焦点恢复，没有把整页观察隐瞒为“全部无障碍通过”。VoiceOver 尚未实测。
- **未通过环境：**Edge 启动失败，`/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge` 不存在；保留失败日志，不计通过，未自行安装浏览器。
- **未验证：**Firefox、最低 Chrome 120、Safari 原生安装、物理触屏、VoiceOver 与商店发布。本轮扩展加载使用 headless Chrome for Testing；不等同于操作用户正在使用的工具栏弹窗。
- **语言限制：**新增文案经用户已授权的翻译接口生成初稿，只发送项目界面文案；50 语言结构完整不等于母语审校。中文与英文检查了实际流程，德文与阿语覆盖代表性布局。
- **政策范围：**沿用当前政策数据，本轮没有重新核验或宣称完成 20 城政策。缺证月份仍拒绝自动估算。政策未完成项继续见 `docs/payroll-policy-coverage.md` 与 `docs/payroll-policy-review-20261106.md`。
- **范围边界：**本轮个税及直接共享兼容验收，不表示其他工具、全部政策或所有浏览器绝对无 Bug。

本轮测试结束后关闭自建浏览器任务，并停止临时 56271 服务。Git、Release 与商店发布仍等待用户后续指令。
