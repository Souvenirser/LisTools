# 20城政策追加核验与候选数据修正（2026-11-13）

**已验证：本轮独立复核并采纳17组字段记录，涉及13城；431项单元测试通过。未完成：20城2026-01—11全字段闭合，正式1.2.8出包门槛仍为0/20。**

本轮只修改政策候选、证据、审计和回归测试；没有修改页面布局或计算引擎，没有新增依赖、生成正式Chrome包、提交Git或发布Release。区域调查的结论先视为线索，主任务重新打开官文/公开接口后才写入`adopted.json`。地区报告中的其他结论保留其原始证据等级，不能自动当作主任务已采纳字段。

## 实际修改

- 重庆：候选单位医疗合计由8.5%更正为10%（基本8%＋大额1.5%＋生育0.5%），生育保持合并行，不重复收取。官方答复是2026-01时点，个人5元/月的支付通道和后续完整有效链仍缺，因此保持reference，不能直接自动试算。
- 福州、济南、天津：补上半年公积金候选；分别为2195—31053、主城五区2400—32586、2320—27861。保留不同地区及新开户条件，不将部分区域下限推广全市。
- 武汉：住房基数按2026自然年度2400—36072.25组织，补入已有有效规范的同率、5%—12%整数规则。7月调整后补差不等于每月现金实际发生相同扣款。
- 成都、长沙：只补已取得原文的全年养老/失业/工伤基数属期，分别为4699—23493、4106—20529。医保、生育的区间未随之改动；费率和金额舍入仍是候选状态。
- 厦门、福州、天津：补正确的住房原件及截至2027-06的通知有效期，不借此扩展其他险种或未来整城支持。
- 苏州：现有住房配置本来就是向上取元，**没有再次改算法**；本轮增加独立算例、原文和新生育办法来源。10001元×7%=700.07元，两侧各进到701元，不能误用四舍五入到700元。
- 北京、广州、杭州等：新增失业、医保、生育、大额/长护账户通道的字段证据，没有把未知值改成0或把账户划转重复算进工资现金。
