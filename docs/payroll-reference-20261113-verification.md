# 1.2.8 参考参数试算版

本轮按用户指令，默认采用提效录参考参数，不再等待20城官方历史全字段核验。原官方资料和严格 `resolvePolicy` 仍保留，未改为已核验。

个人费率和统一上下限来自首页计算器实际使用的参数；单位费率来自对应城市页单位列。参考站静态个人表将工伤、生育列为非零，但其实际计算器未扣这两项，本版按实际计算逻辑计为0。表单网的单位养老20%与提效录16%不同，本版不混用。

公积金默认7%，双方可分别设置。各项先用Decimal四舍五入到分，再求和；不复制参考站JavaScript浮点运算误差。所有月份采用同一采集快照，不冒称对应历史月份的实际政策。

## 失败记录与修正

- 参考入口初轮测试5项失败，最小实现后通过；后续新增来源哈希用例先失败，修正城市URL误配首页哈希，导出同时保留首页与城市来源。
- 初轮现有浏览器回归60项通过、4项失败；均为旧官方参数断言（额外3元、上海单位未知等）与本次明确选定的参考口径冲突。独立复算并调整期待值后，最终79项全部通过，没有删除相应保护场景。
- 第一次隔离包仍被动态入口引入支持页JS/CSS，逐文件检查拒绝该产物。修正隔离副本的动态入口后重建，仅交付通过排除检查的包。
- 本轮没有操作可用的Ego用户浏览器空间；该空间已不存在。参考站参数通过公开页面HTML实际读取；浏览器验收使用独立无登录测试环境，不宣称在参考站实际点击了所有计算。

## 未验证与边界

- 本版按用户指定参考站参数试算，不构成20城2026年各历史段官方核验结论；旧政策资料保持原验证状态。不能用本轮通过数证明参考站数据是各地实际现行缴费政策。
- 金额按项目取分再合计；未复制参考站浮点尾差、静态表与实际个人扣费不一致的部分。参考站单位列为静态费率，本版单位结果是依该列计算的估算。
- 未执行Edge、Firefox、最低Chrome120、Safari原生安装、VoiceOver、物理触屏。原生缩放为中文明暗检查，不冒称所有语言和所有工具均已执行。
- 新增3项文案覆盖现有50语言，完整单元的键及插值检查通过；未进行50语言母语审校。未重跑无关工具的全站浏览器矩阵。
- 现有Vite大chunk警告保留，未借本轮重构无关模块。源码快照仅在候选构建中改动支持页排除；工作区其他修改和历史包未覆盖。
